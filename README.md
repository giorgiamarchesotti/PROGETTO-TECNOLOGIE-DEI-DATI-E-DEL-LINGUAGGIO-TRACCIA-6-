# Progetto per l'esame di Tecnologie dei dati e del linguaggio
**Traccia 6:** Il gran rifiuto

## Descrizione del progetto
Questo repository contiene il codice, i dati e il report di un'indagine empirica sull'interazione tra modelli linguistici (LLM) e frammenti di cronaca giudiziaria complessa (ispirati al caso dei "Diavoli della Bassa Modenese" e al podcast *Veleno*). 

## Contenuti del repository
* `Untitled.ipynb`: Il taccuino Google Colab con il codice Python per l'esecuzione dei test.
* `risultati_test_rifiuti_ampliato.json`: Il dataset con i risultati strutturati delle risposte del modello.
* `report.html`: Il report statico finale comprensivo di analisi e grafici.
* `grafico_test.png`: La visualizzazione grafica degli esiti sperimentali.
